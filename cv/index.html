Selected Infrastructure & Engineering Work

SAML to OIDC Authentication Migration

IDENTITY · PLATFORM ENGINEERING · SECURITY

Replaced SAML authentication with OIDC in a shared internal authentication package responsible for user authentication and role-based access control. Designed the integration to remain fully backwards compatible, allowing existing applications to continue using SAML while enabling migration to OIDC through a configuration switch.

Simplified adoption by providing convenience functions for applications to start and configure the authentication supervision tree as part of their application startup, reducing the integration work required by consuming teams.

Built a purpose-designed fake OIDC identity provider for integration testing. The provider implements only the endpoints required by the authentication flow, while supporting the complete flow from authorization through callback, token exchange and user information, including sessions populated with identity claims and userinfo data.

This enabled end-to-end authentication tests against a real HTTP-based identity-provider flow without depending on an external identity provider, while keeping the test environment deterministic and under application control.

Distributed Tracing for Oban Job Pipelines

OBSERVABILITY

Extended Oban with distributed tracing to make asynchronous job pipelines observable end-to-end. Built a wrapper around job creation that starts or attaches the current span context and propagates tracing information into newly enqueued jobs.

Integrated with Oban's telemetry events to track job lifecycle events, including completions, retries and exceptions. Extended the same tracing model to cron jobs scheduled during application startup, ensuring scheduled workloads were connected to the application's trace context.

Added OpenObserve trace deep links to job metadata, allowing engineers to move directly from an Oban job to its corresponding trace when investigating production behavior.

The resulting instrumentation made it possible to follow an entire asynchronous pipeline in a single trace: from an initial job enqueue, through jobs that enqueue subsequent work, to completion, retries and failures.

OpenTelemetry · OpenObserve · Elixir · Oban

Error Tracker Notifications

RELIABILITY · TESTING · INTEGRATIONS

Took ownership of an existing error-notification implementation that had been delivered without test coverage. Backfilled unit tests and refactored the implementation to establish clear boundaries between three concerns: error-state business logic, notification rendering, and the external HTTP integration with Azure Workflows used to deliver notifications to Microsoft Teams.

The resulting test isolation made it possible to independently verify error lifecycle behavior, including new occurrences and errors that had previously been considered resolved, without coupling business logic tests to notification formatting or external services.

With the behavior covered and the integration boundaries established, extended the system to support multiple teams and multiple notification workflows within a shared monorepo, allowing each team to route error notifications to its own Microsoft Teams channel.

The work also resulted in a contribution to the open-source project used by the implementation, addressing a limitation encountered while extending the integration.
